# Product and Market Review

Scope: five direct healthcare access/automation competitors, using official product material: Hyro, Syllable, Phreesia, NexHealth, and Luma Health.

## Classification

| Class | Recommendation |
|---|---|
| Release must-have | Canonical executable actions, rule-bound scheduling, truthful entitlements/integration state, human handoff, idempotent financial/payer operations, observable queue recovery |
| Small architectural enabler | Environment-scoped queue names, durable provider request/outbox identity, execution receipts, integration capability contracts |
| Next-release differentiator | Multilingual voice, smart waitlist/referral workflows, client ROI/usage reporting, broader EHR/PM adapters |
| Long-term market bet | Reseller/white-label operating model and regional data-residency controls |

The strongest potential differentiation is a unified operational and financial control plane with evidence-backed automation. Today that proposition is weakened by missing EHR/PM integration breadth, claims workflows, automated payer prior authorization, eligibility idempotency, provider-profile onboarding, and incomplete support tooling.

Commercially supportable packaging should combine a base/location tier with metered voice, messaging, eligibility, storage, and premium integrations, while exposing usage and ROI to customers. Current entitlement behavior exists, but onboarding and disconnected/setup-required states need a guided client workflow before enterprise sales demonstrations can be self-service.
