# CareCommand Demo Experience Release

This branch is a presentation-layer hardening pass for the client pilot. It intentionally preserves backend contracts, authorization, tenancy, audit, and clinical workflows while modernizing the shared staff application shell and design system.

Acceptance target:
- visibly distinct from the prior production shell
- compact, modern, premium healthcare operations aesthetic
- no fake data or decorative metrics
- no weakening of accessibility, RBAC, RLS, or audit controls
- shared-shell changes first so all modules benefit consistently
- browser-visible demo flow remains the release gate
